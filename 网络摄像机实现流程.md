## 总体流程概览

```
用户配置 → 数据存储 → 设备选择 → 源创建 → 视频解码 → 帧渲染 → UI显示
```

### 支持的摄像机类型

| 类型 | 协议 | 说明 |
|------|------|------|
| `stream` | RTSP/RTMP/HLS/HTTP/FTP | 标准网络串流 |
| `onvif` | ONVIF | ONVIF协议网络摄像机（自动协商RTSP地址） |
| `mr` | 自定义TCP | MR 3D定位摄像机 |
| `gosuncn` | 自定义协议 | GOSUNCN专用摄像机 |

### 3.2 SourceWidget异步加载视频源

**方法**: [`SourceWidget::loadSource()`](f:\eb4\ViewKit2\SourceWidget.cpp#L79)

**执行方式**: 在后台线程池 (`g_threadpool`) 中创建对应的RenderSource对象

**核心代码**:
```cpp
void SourceWidget::loadSource()
{
    state = SourceOpenState::Opening;
    
    // 在后台线程中创建RenderSource对象
    g_threadpool->enqueue([this]() {
        Json::Value jc = config;
        string type = jc["type"].asString();
        string id = jc["id"].asString();
        
        RenderSource* source = nullptr;
        bool ret = false;
        
        if (type == "stream") {
            // RTSP/RTMP流
            string url = jc["config"]["url"].asString();
            string user = JSON_STR(jc["config"], "user");
            string pwd = JSON_STR(jc["config"], "pwd");
            
            RenderSourceStream* rs = new RenderSourceStream(id);
            ret = rs->create(url, user, pwd);
            source = rs;
        }
        else if (type == "onvif") {
            // ONVIF协议摄像机
            Json::Value jv = jc["device"];
            string url = jv["url"].asString();
            string user = JSON_STR(jv, "user");
            string pwd = JSON_STR(jv, "pwd");
            
            RenderSourceONVIF* rs = new RenderSourceONVIF(id);
            ret = rs->create(url, user, pwd);
            source = rs;
        }
        else if (type == "mr") {
            // MR摄像机
            vector<string> v_addr;
            strSplit(url, ':', v_addr);
            if (v_addr.size() == 2) {
                RenderSourceMR* rs = new RenderSourceMR(id);
                ret = rs->create(v_addr[0], atoi(v_addr[1].c_str()), user, pwd);
                source = rs;
            }
        }
        
        if (ret && source != nullptr) {
            // 绑定更新信号
            source->sig_updated.connect([=](const uint8_t*, int, int, int) {
                InvalidateRect(_hWnd, NULL, TRUE);
            });
            
            state = SourceOpenState::Success;
        }
        else {
            state = SourceOpenState::Failed;
            delete source;
            source = nullptr;
        }
    });
}
```

## 阶段四：建立连接与获取视频流

### 4.1 ONVIF摄像机的特殊处理

**方法**: [`RenderSourceONVIF::create()`](f:\eb4\ViewKit2\RenderSource.cpp#L583)

**处理流程**:

1. **打开ONVIF设备**: 
   ```cpp
   void* onvif_ctx = MCX_OnvifCamera_Open(url.c_str(), user.c_str(), pwd.c_str());
   ```

2. **获取RTSP地址**:
   ```cpp
   char rtspUrl[1024] = { 0 };
   MCX_OnvifCamera_GetRtspUrl(onvif_ctx, rtspUrl);
   ```
   - ONVIF协议会返回多个码流地址（主码流/子码流）
   - 地址以逗号分隔存储在 `mediaUrls` 中

3. **解析多个码流地址**:
   ```cpp
   string urls(rtspUrl);
   vector<string> mediaUrls;
   split(urls, ',', mediaUrls);
   ```

4. **选择当前URL**:
   ```cpp
   bool autoToggle = DataManager::getInst()->getConfigAsBool("autoToggle", true);
   currentUrl = autoToggle ? mediaUrls.back()   // 子码流（低分辨率，节省带宽）
                           : mediaUrls.front(); // 主码流（高分辨率）
   ```

5. **关闭ONVIF上下文**（只需获取一次地址）:
   ```cpp
   MCX_OnvifCamera_Close(onvif_ctx);
   ```

6. **打开视频流**:
   ```cpp
   openUrl(currentUrl);
   ```

**完整代码**:
```cpp
bool RenderSourceONVIF::create(const string& url, const string& user, const string& pwd)
{
    // 1. 打开ONVIF设备
    void* onvif_ctx = MCX_OnvifCamera_Open(url.c_str(), user.c_str(), pwd.c_str());
    if (!onvif_ctx) return false;
    
    // 2. 获取RTSP地址列表（主码流、子码流等）
    char rtspUrl[1024] = { 0 };
    MCX_OnvifCamera_GetRtspUrl(onvif_ctx, rtspUrl);
    
    // 解析多个码流地址（逗号分隔）
    string urls(rtspUrl);
    strSplit(urls, ',', mediaUrls);
    
    // 3. 根据配置选择码流
    bool autoToggle = DataManager::getInst()->getConfigAsBool("autoToggle", true);
    currentUrl = autoToggle ? mediaUrls.back() : mediaUrls.front();
    
    // 4. 关闭ONVIF上下文（只需获取一次地址）
    MCX_OnvifCamera_Close(onvif_ctx);
    
    // 5. 使用RTSP地址打开视频流
    return openUrl(currentUrl);
}
```

### 4.2 普通RTSP/RTMP流的直接打开

```cpp
bool RenderSourceStream::create(const string& url, const string& user, const string& pwd)
{
    // 拼接认证信息到URL
    string url1 = makeUrl(url, user, pwd);
    
    if (RenderSourceVideo::create(str2wstr(url1))) {
        // 2秒后刷新缓冲区（避免初始卡顿）
        g_threadpool->enqueue([=]() {
            Sleep(2000);
            MCX_Player_Flush(videoPlayer);
        });
        streamUrl = url1;
        return true;
    }
    return false;
}

// URL拼接辅助函数
string RenderSourceStream::makeUrl(const string& url, const string& user, const string& pwd)
{
    string url1 = url;
    if (user != "" && pwd != "") {
        size_t p = url1.find("://");
        if (p != string::npos) {
            url1.insert(p + 3, user + ":" + pwd + "@");
        }
    }
    return url1;
}
```

**示例**:
- 原始URL: `rtsp://192.168.1.100:554/stream1`
- 拼接后: `rtsp://admin:password123@192.168.1.100:554/stream1`

### 6.1 解码器工作

- 硬件加速：NVIDIA NVENC/NVDEC (CUDA)

**工作流程**:
```
网络接收 → 解封装 → 解码 → RGB转换 → 回调通知
```

### 6.2 视频帧回调机制

当解码器获得新帧时，调用 [`RenderSource::onDisplay()`](f:\eb4\ViewKit2\RenderSource.cpp#L186)

**静态回调函数**:
```cpp
void RenderSource::onDisplay(const uint8_t* data, int width, int height, 
                             int stride, void* userdata)
{
    RenderSource* rs = (RenderSource*)userdata;
    if (rs->allReady) {
        rs->update(data, width, height, stride);  // 触发更新信号
    }
}
```

**参数说明**:
- `data`: 视频帧数据指针
  - 如果 `stride < width`，表示是D3D11共享纹理句柄
  - 否则是RGB32格式的像素数据
- `width`: 帧宽度
- `height`: 帧高度
- `stride`: 行步长（字节数）
- `userdata`: RenderSource实例指针

## 阶段七：信号传递与图像更新

### 7.1 触发更新信号

**方法**: [`RenderSource::update()`](f:\eb4\ViewKit2\RenderSource.cpp#L192)

**功能**:
1. 生成缩略图
2. YOLO目标检测（如果启用）
3. 截图处理
4. 发出Boost信号通知所有监听者

**核心代码**:
```cpp
void RenderSource::update(const uint8_t* data, int width, int height, int stride)
{
    // 检查有效性
    if (width <= 0 || height <= 0) {
        allReady = false;
        string* pid = new string(id);
        PostMessage(FindWindow(L"MainWindow_ViewKit", NULL), WMU_SOURCEREMOVE, (WPARAM)pid, NULL);
        return;
    }
    
    if (stride < width) {
        // D3D11共享纹理方式
        D3D11Frame* d3dFrame = (D3D11Frame*)data;
        thumbnail.update(d3dFrame->thumbnail->data, 
                        d3dFrame->thumbnail->width, 
                        d3dFrame->thumbnail->height, 
                        d3dFrame->thumbnail->stride, 2.0);
    }
    else {
        // 生成缩略图（缩小到160像素宽）
        thumbnail.update(data, width, height, stride, 160.0 / width);
        
        // YOLO检测（如果启用）
        if (enableDetect) {
            SourceManager::getInst()->detectFrame(id, data, width, height, stride);
        }
        
        // 截图处理
        if (snapshot) {
            MyBuffer* buff = new MyBuffer(data, stride * height);
            g_threadpool->enqueue([=]() {
                wstring filePath = DataManager::getInst()->getSaveDir() + L"\\" + 
                                  validateFileName(name) + L"-" + getCurrentTime();
                
                if (DataManager::getInst()->getConfigAsString("snapFormat", "JPEG") == "JPEG")
                    filePath += L".jpg";
                else
                    filePath += L".png";
                
                Gdiplus::Bitmap bitmap(width, height, stride, PixelFormat32bppRGB, 
                                      (uint8_t*)buff->getBuffer());
                saveImage(&bitmap, filePath);
                delete buff;
            });
            snapshot = false;
        }
    }
    
    // 关键：发出更新信号，通知所有监听者
    sig_updated(data, width, height, stride);
}
```

```cpp
void RenderImage::onSourceUpdate(const uint8_t* data, int width, int height, int stride)
{
    if (!attach) return;
    
    auto engine = window->getEngine();
    int needCreate = (stride < width) ? -1 : 1;
    
    do {
        engine->Lock();
        
        if (bitmap != nullptr) {
            auto sz = bitmap->GetPixelSize();
            if (sz.width == width && sz.height == height) {
                if (stride < width) {
                    // D3D11共享纹理方式（零拷贝，高性能）
                    if (sharedTexture != NULL) {
                        needCreate = 0;
                        D3D11Frame* d3dFrame = (D3D11Frame*)data;
                        CComPtr<ID3D11Texture2D> tex;
                        
                        if (!VideoFactory::getInst()->frozen && 
                            SUCCEEDED(engine->getD3D11Device()->OpenSharedResource(
                                d3dFrame->sharedHandle, 
                                __uuidof(ID3D11Texture2D), 
                                (void**)&tex))) {
                            
                            CComPtr<IDXGIKeyedMutex> dxgiMutex;
                            tex->QueryInterface(__uuidof(IDXGIKeyedMutex), (void**)&dxgiMutex);
                            
                            if (SUCCEEDED(dxgiMutex->AcquireSync(0, INFINITE))) {
                                // 拷贝纹理到共享资源（GPU内部操作，零CPU参与）
                                engine->getD3D11Context()->CopyResource(sharedTexture, tex);
                                dxgiMutex->ReleaseSync(0);
                            }
                        }
                    }
                }
                else {
                    // 直接内存拷贝方式
                    needCreate = 0;
                    auto dest = D2D1::RectU(0, 0, width, height);
                    if (visible && !VideoFactory::getInst()->frozen) {
                        bitmap->CopyFromMemory(&dest, data, stride);
                    }
                }
            }
        }
        
        engine->UnLock();
        
        // 如果需要重新创建位图
        if (needCreate == -1) {
            createSharedBitmap(width, height);  // D3D11共享纹理
            needCreate = 1;
        }
        
    } while (needCreate != 0);
}
```

**两种更新方式对比**:

| 方式 | 适用场景 | 性能 | 说明 |
|------|---------|------|------|
| D3D11共享纹理 | `stride < width` | ⚡⚡⚡ 极高 | GPU内部拷贝，零CPU参与 |
| 直接内存拷贝 | `stride >= width` | ⚡⚡ 中等 | CPU到GPU传输，有带宽开销 |

### 7.3 创建Direct2D位图

**方法**: [`RenderImage::createBitmap()`](f:\eb4\ViewKit2\RenderImage.cpp#L40)

**核心代码**:
```cpp
bool RenderImage::createBitmap(int width, int height, const uint8_t* data)
{
    auto* engine = window->getEngine();
    engine->Lock();
    freeBitmap();
    
    // 创建D2D位图
    HRESULT hr = engine->getContext()->CreateBitmap(
        D2D1::SizeU(width, height),
        D2D1::BitmapProperties(
            D2D1::PixelFormat(DXGI_FORMAT_B8G8R8A8_UNORM, D2D1_ALPHA_MODE_PREMULTIPLIED)
        ),
        &bitmap
    );
    
    // 拷贝初始数据
    if (data != nullptr && SUCCEEDED(hr)) {
        auto dest = D2D1::RectU(0, 0, width, height);
        bitmap->CopyFromMemory(&dest, data, width * 4);
    }
    
    engine->UnLock();
```

```cpp
{
    auto* engine = window->getEngine();
    
    HRESULT hr = S_OK;
    D3D11_TEXTURE2D_DESC texDesc;
    texDesc.Width = width;
    texDesc.Height = height;
    texDesc.MipLevels = 1;
    texDesc.ArraySize = 1;
    texDesc.Format = DXGI_FORMAT_B8G8R8A8_UNORM;
    texDesc.SampleDesc.Count = 1;
    texDesc.SampleDesc.Quality = 0;
    texDesc.Usage = D3D11_USAGE_DEFAULT;
    texDesc.CPUAccessFlags = 0;
    texDesc.BindFlags = D3D11_BIND_SHADER_RESOURCE;
    texDesc.MiscFlags = 0;

    hr = sharedTexture->QueryInterface(__uuidof(IDXGISurface), (void**)&sharedSurface);
    ASSERT(SUCCEEDED(hr));

    auto prop = D2D1::BitmapProperties(
        D2D1::PixelFormat(DXGI_FORMAT_B8G8R8A8_UNORM, D2D1_ALPHA_MODE_PREMULTIPLIED)
    );
    hr = engine->getContext()->CreateSharedBitmap(
        __uuidof(IDXGISurface), 
        sharedSurface, 
        &prop, 
        &bitmap
    );
    
    ASSERT(SUCCEEDED(hr));
    engine->UnLock();
```

### 8.2 渲染循环绘制

**类**: [`RenderWindow`](f:\eb4\ViewKit2\RenderWindow.cpp)

**渲染引擎**: [`RenderEngine`](f:\eb4\ViewKit2\RenderEngine.h) 使用Direct2D进行GPU加速渲染

**绘制流程**:

1. 每帧调用 `RenderWindow::onDraw()`
2. 遍历所有 `RenderLayout` 和 `RenderBox`
3. 获取每个Box的Bitmap
4. 应用变换矩阵（缩放、旋转、平移）
5. 使用 `ID2D1RenderTarget::DrawBitmap()` 绘制到屏幕

**核心代码**:
```cpp
void RenderWindow::onDraw()
{
    auto engine = getEngine();
    auto context = engine->getContext();
    
    // 开始绘制
    context->BeginDraw();
    context->Clear(D2D1::ColorF(D2D1::ColorF::Black));
    
    // 遍历所有布局和Box进行绘制
    for (auto& layout : layouts) {
        // 应用布局变换
        D2D1::Matrix3x2F transform = layout->getTransform(layoutWidth, layoutHeight);
        context->SetTransform(transform);
        
        for (auto& box : layout->getBoxes()) {
            auto bitmap = box->getBitmap();
            if (bitmap != nullptr) {
                // 获取Box的渲染矩形
                D2D1_RECT_F rect = box->getRenderRect();
                
                // 绘制位图
                context->DrawBitmap(bitmap, rect);
            }
        }
    }
    
    // 结束绘制并呈现
    HRESULT hr = context->EndDraw();
    if (hr == D2DERR_RECREATE_TARGET) {
        engine->recreateTarget();  // 重建渲染目标
    }
}
```

**渲染优化**:
- **批处理**: 相同状态的绘制命令合并
- **脏矩形**: 只重绘变化区域
- **双缓冲**: 避免闪烁
- **GPU加速**: 所有操作在GPU完成

```cpp
void RenderImage::onSourceUpdate(const uint8_t* data, int width, int height, int stride)
{
    if (!attach) return;
    
    auto engine = window->getEngine();
    engine->Lock();
    
    if (bitmap != nullptr) {
        auto sz = bitmap->GetPixelSize();
        if (sz.width == width && sz.height == height) {
            if (stride < width) {
                // D3D11共享纹理方式（零拷贝，高性能）
                if (sharedTexture != NULL) {
                    D3D11Frame* d3dFrame = (D3D11Frame*)data;
                    CComPtr<ID3D11Texture2D> tex;
                    
                    if (!VideoFactory::getInst()->frozen && 
                        SUCCEEDED(engine->getD3D11Device()->OpenSharedResource(
                            d3dFrame->sharedHandle, 
                            __uuidof(ID3D11Texture2D), 
                            (void**)&tex))) {
                        
                        CComPtr<IDXGIKeyedMutex> dxgiMutex;
                        tex->QueryInterface(__uuidof(IDXGIKeyedMutex), (void**)&dxgiMutex);
                        
                        if (SUCCEEDED(dxgiMutex->AcquireSync(0, INFINITE))) {
                            // 拷贝纹理到共享资源
                            engine->getD3D11Context()->CopyResource(sharedTexture, tex);
                            dxgiMutex->ReleaseSync(0);
                        }
                    }
                }
            }
            else {
                // 直接内存拷贝方式
                auto dest = D2D1::RectU(0, 0, width, height);
                if (visible && !VideoFactory::getInst()->frozen) {
                    bitmap->CopyFromMemory(&dest, data, stride);
                }
            }
        }
    }
    
    engine->UnLock();
}
```

| **渲染层** | RenderImage<br>RenderBox | GPU显存管理 | Direct2D + D3D11 |
| **引擎层** | RenderEngine | 渲染上下文管理 | GPU加速渲染 |

### ⚡ 性能优化技术

#### 1. 异步非阻塞架构
- **解码线程**: 独立的解码线程，不阻塞UI主线程
- **线程池**: 使用 `g_threadpool` 处理耗时操作
- **消息队列**: Windows消息机制实现线程间通信

#### 2. GPU零拷贝渲染
- **D3D11共享纹理**: 解码器直接输出到GPU显存
- **IDXGIKeyedMutex**: 同步访问共享资源
- **CopyResource**: GPU内部拷贝，无需CPU参与

**性能对比**:
```
传统方式: 解码(CPU) → 内存拷贝 → GPU上传 → 渲染  ≈ 15-20ms延迟
零拷贝:   解码(GPU) → 共享纹理 → 直接渲染        ≈ 2-5ms延迟
```

#### 3. 信号槽解耦
- **Boost.Signals2**: 类型安全的回调机制
- **松耦合**: 解码器和渲染器完全独立
- **多播**: 一个信号可以连接多个槽函数

**示例**:
```cpp
// RenderSource发出信号
sig_updated(data, width, height, stride);

// 多个监听者接收
renderImage->connection = source->sig_updated.connect(...);
yoloDetector->connection = source->sig_updated.connect(...);
thumbnailGenerator->connection = source->sig_updated.connect(...);
```

#### 4. 智能缓存策略
- **缩略图缓存**: 自动生成160px宽的缩略图
- **初始帧缓存**: 保存第一帧作为预览
- **位图复用**: RenderImage复用D2D Bitmap，避免频繁创建销毁

#### 5. 批量渲染优化
- **批处理**: 相同状态的绘制命令合并
- **脏矩形**: 只重绘变化区域
- **双缓冲**: 前后缓冲切换，避免闪烁

## 常见问题与解决方案

### ❓ Q1: 视频卡顿或延迟高

**原因**:
- 网络带宽不足
- 使用了主码流（高分辨率）
- CPU软解码性能不足

**解决方案**:
```cpp
// 1. 切换到子码流
DataManager::getInst()->setConfig("autoToggle", true);

// 2. 启用硬件解码
DataManager::getInst()->setConfig("decoder", "cuda");

// 3. 降低分析时长
DataManager::getInst()->setConfig("analyze", 200);  // 默认500ms
```

### ❓ Q2: ONVIF摄像机无法连接

**原因**:
- ONVIF服务未启用
- 认证失败
- 端口被防火墙阻止

**解决方案**:
```cpp
// 1. 检查ONVIF服务是否启用（摄像机Web界面）
// 2. 确认用户名密码正确
// 3. 开放端口554(RTSP)和80/8080(ONVIF)

// 调试日志
g_log->print(LOG_Level_Debug, "ONVIF URL: %s", url.c_str());
```

### ❓ Q3: 画面黑屏或花屏

**原因**:
- 解码器不支持该编码格式
- GPU驱动过旧
- 分辨率超出支持范围

**解决方案**:
```cpp
// 1. 切换到软件解码
DataManager::getInst()->setConfig("decoder", "software");

// 2. 更新NVIDIA显卡驱动
// 3. 检查编码器格式
g_log->print(LOG_Level_Info, "Codec: %s", mediaInfo["video"]["codec"].asString().c_str());
```

### ❓ Q4: 内存泄漏

**原因**:
- RenderSource未正确释放
- 信号连接未断开

**解决方案**:
```cpp
// 确保正确释放
RenderSource::~RenderSource()
{
    close();  // 断开信号连接
    if (initData != nullptr)
        delete initData;
}

// 检查引用计数
boost::shared_ptr<RenderSource> rs = SourceManager::getInst()->getSource(id);
```
