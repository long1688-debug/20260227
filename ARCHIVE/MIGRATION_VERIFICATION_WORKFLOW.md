## 🐛 常见问题排查

### 问题1：编译错误 - 变量重复声明

**症状**:
```
Identifier 'xxx' has already been declared.
```

**原因**: 
从 useVideoSync 解构后，又有本地 ref/computed 声明

**解决**:
```bash
# 运行检查脚本定位问题
npm run check:migration

# 或手动搜索
grep -n "const xxx =" tauri-app/src/components/TeacherWindow.vue
```

**预防**: 
- 每次从 useVideoSync 解构新变量时，立即搜索是否有重复声明
- 使用检查脚本自动检测

---

### 问题2：运行时错误 - Cannot read properties of undefined

**症状**:
```
TypeError: Cannot read properties of undefined (reading 'xxx')
```

**可能原因**:
1. Props 名称不匹配
2. 事件参数传递不完整
3. 数据未正确初始化

**排查步骤**:
```javascript
// 1. 检查 Props 定义
console.log('Props:', props)

// 2. 检查事件参数
@event="(arg1, arg2) => $emit('event', arg1, arg2)"

// 3. 检查数据初始化
console.log('Data:', reactiveData.value)
```

---

### 问题3：UI 不更新

**症状**: 
数据已修改，但界面未刷新

**可能原因**:
1. 直接修改了响应式数组（违反规范）
2. 使用了错误的响应式 API

**解决**:
```javascript
// ❌ 错误：直接操作数组
videoPreviews.value.push(source)
videoPreviews.value.splice(index, 1)

// ✅ 正确：使用方法
addVideoSource(source)
removeVideoSource(sourceId)
```

---

### 问题4：状态不一致

**症状**: 
不同组件显示的数据不一致

**可能原因**:
1. 多个状态源
2. 未正确使用 Composable

**排查**:
```javascript
// 确保只有一个 useVideoSync 实例
// 在 TeacherWindow 中创建
const { currentLayout } = useVideoSync()

// 子组件通过 Props 接收
// 不要再次调用 useVideoSync()
```

## 📝 代码审查清单

### 提交前自查

- [ ] 运行 `npm run check:migration` 并通过
- [ ] 运行 `get_problems` 无错误
- [ ] 启动 `npm run dev` 编译成功
- [ ] 核心功能手动测试通过
- [ ] 无 console.error 警告
- [ ] 无未使用的导入
- [ ] 注释清晰，关键逻辑有说明

### Code Review 重点

1. **导入检查**
   - [ ] 是否从 useVideoSync 导入而非 useVideoStore
   - [ ] 导入的变量是否都使用了
   - [ ] 有无重复导入

2. **状态管理**
   - [ ] 是否直接操作响应式数组
   - [ ] 是否正确解构所需变量
   - [ ] 有无重复声明

3. **组件通信**
   - [ ] Props 名称是否一致
   - [ ] Emits 是否正确转发多参数事件
   - [ ] 事件处理函数是否定义

4. **性能优化**
   - [ ] 有无不必要的重渲染
   - [ ] 事件监听器是否正确清理
   - [ ] 计算属性是否合理使用

## 💡 最佳实践

### 1. 小步迭代
- 每次只修改一个功能模块
- 修改后立即验证
- 避免大规模同时修改

### 2. 即时验证
- 每次 `edit_file` 后运行 `get_problems`
- 每次修改后运行 `check:migration`
- 发现问题立即修复

### 3. 文档同步
- 修改代码时同步更新注释
- 重大变更更新本文档
- 记录遇到的问题和解决方案

### 4. 团队沟通
- 提交代码时详细说明变更
- 遇到问题及时同步团队
