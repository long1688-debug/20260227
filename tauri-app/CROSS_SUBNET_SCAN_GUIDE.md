# 跨网段摄像机扫描功能说明

## 问题背景

默认情况下，ONVIF设备发现只能扫描到**同一网段**的摄像机，这是因为：

1. **ONVIF WS-Discovery使用UDP多播**（239.255.255.250:3702），而UDP多播通常不会跨越路由器边界
2. **子网扫描只扫描本地网络接口**，无法访问其他网段

## 解决方案

我们新增了**跨网段扫描**功能，可以探测其他网段的摄像机设备。

## 使用方法

### 1. 选择扫描模式

在摄像机发现面板中，选择 **"🚀 跨网段扫描"** 模式。

### 2. 配置目标网段

在"目标网段列表"中输入要扫描的网段，支持以下格式：

#### CIDR格式（推荐）

```
192.168.2.0/24
192.168.3.0/24
10.0.1.0/24
```

#### 每行一个网段或使用逗号分隔

```
192.168.2.0/24, 192.168.3.0/24, 10.0.1.0/24
```

### 3. 点击"开始扫描"

系统会并发扫描所有配置的网段，并显示发现的设备。

## 前提条件

跨网段扫描需要满足以下条件：

1. **网络路由可达**：当前主机必须能够路由到目标网段
2. **防火墙允许**：防火墙必须允许访问目标网段的相关端口（80, 554, 8000, 8080等）
3. **正确的网段配置**：必须正确配置目标网段的CIDR地址

## 常见网段示例

### 家庭/小型办公室

```
192.168.1.0/24    # 主网段
192.168.2.0/24    # IoT设备网段
192.168.3.0/24    # 访客网段
```

### 企业网络

```
10.0.1.0/24       # 办公区A
10.0.2.0/24       # 办公区B
10.0.10.0/24      # 服务器区
172.16.1.0/24     # 监控专网
```

## 技术实现

### 后端（Rust）

1. **新增函数**：`scan_configured_subnets()` 和 `scan_specific_subnets()`
   - 从环境变量或参数读取目标网段列表
   - 为每个网段生成主机列表
   - 并发扫描所有主机的常见摄像机端口
   - 验证设备是否为真正的摄像机

2. **Tauri命令**：`scan_specific_subnets`
   - 接收前端传入的网段列表
   - 调用后端扫描函数
   - 返回发现的设备列表

### 前端（Vue）

1. **UI组件**：
   - 新增"跨网段扫描"单选按钮
   - 文本域输入框用于配置目标网段
   - 加载示例和清空按钮

2. **辅助函数**：
   - `parseSubnetList()`: 解析用户输入的网段列表
   - `loadExampleSubnets()`: 加载示例网段
   - `clearSubnets()`: 清空网段列表

## 性能优化

1. **并发扫描**：使用 `join_all` 并发扫描所有主机
2. **快速验证**：通过多种协议（ONVIF、RTSP、厂商API）快速验证设备身份
3. **去重机制**：自动去除重复发现的设备

## 注意事项

1. **扫描时间**：扫描多个网段可能需要较长时间，建议设置合理的超时时间（5-10秒）
2. **网络负载**：大规模扫描可能产生较多网络流量，建议在非高峰时段进行
3. **权限要求**：某些网络环境可能需要特殊权限才能访问其他网段
4. **路由器限制**：某些路由器可能禁止跨网段访问，需要调整路由器配置

## 故障排除

### 问题1：扫描不到任何设备

**可能原因**：

- 网络路由不可达
- 防火墙阻止访问
- 网段配置错误

**解决方法**：

1. 使用 `ping` 测试是否能访问目标网段的某个IP
2. 检查防火墙规则
3. 确认网段CIDR配置正确

### 问题2：扫描速度很慢

**可能原因**：

- 超时时间设置过长
- 网段范围太大（如 /16）

**解决方法**：

1. 减小超时时间（建议3-5秒）
2. 使用更精确的网段（如 /24 而不是 /16）
3. 分批扫描不同网段

### 问题3：发现大量非摄像机设备

**可能原因**：

- 验证逻辑不够严格

**解决方法**：

- 系统已内置严格的设备验证机制
- 只会识别真正的摄像机设备（通过ONVIF、RTSP、厂商API验证）

## 高级配置

### 环境变量配置

可以通过环境变量预设常用的扫描网段：

```bash
# Windows PowerShell
$env:CAMERA_SCAN_SUBNETS="192.168.2.0/24,192.168.3.0/24,10.0.1.0/24"

# Linux/Mac
export CAMERA_SCAN_SUBNETS="192.168.2.0/24,192.168.3.0/24,10.0.1.0/24"
```

这样在启动应用时会自动扫描这些网段。

## 与其他扫描模式的对比

| 扫描模式 | 适用范围 | 速度 | 配置复杂度 |
|---------|---------|------|-----------|
| 多网卡扫描 | 所有本地网卡所在的网段 | 快 | 低 |
| 自动子网扫描 | 当前主网段 | 最快 | 最低 |
| **跨网段扫描** | **任意配置的网段** | **中等** | **中等** |
| 综合发现 | 本地网段 + ONVIF多播 | 慢 | 中等 |
| 手动指定 | 指定的IP范围 | 取决于范围 | 高 |

## 总结

跨网段扫描功能突破了传统ONVIF发现的网段限制，使得在复杂网络环境中发现摄像机变得更加灵活和高效。只需简单配置目标网段，即可扫描整个企业网络中的摄像机设备。
