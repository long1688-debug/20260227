# 跨网段扫描功能使用说明

## ✅ 功能已完成

已在"添加信号源"对话框中完成跨网段扫描功能的集成。

## 📍 功能位置

**路径：** 教师窗口 → 添加信号源 → 网络摄像机

## 🎯 使用步骤

### 1. 打开添加信号源对话框

- 点击教师窗口的"添加信号源"按钮
- 选择"网络摄像机"类型

### 2. 选择扫描模式

在网络摄像机界面顶部，您会看到两个扫描模式选项：

- **🔍 自动扫描**：扫描本地所有网络接口（包括主网卡和副网卡）
- **🚀 跨网段扫描**：扫描指定的其他网段

### 3. 使用跨网段扫描

#### 步骤

1. 选择"🚀 跨网段扫描"单选按钮
2. 在"目标网段列表"文本框中输入要扫描的网段（CIDR格式）
3. 点击"开始扫描"按钮

#### 网段格式示例

```
192.168.2.0/24
192.168.3.0/24
10.0.1.0/24
```

**说明：**

- 每行一个网段
- 使用CIDR格式：`IP地址/子网掩码位数`
- `/24` 表示C类子网（256个IP地址）
- `/16` 表示B类子网（65536个IP地址）

#### 快捷操作

- **加载示例**：点击"加载示例"按钮快速填入示例网段
- **清空**：点击"清空"按钮清除所有网段

### 4. 查看扫描结果

扫描完成后，发现的摄像机会显示在表格中：

- IP地址
- MAC地址
- 设备名称
- 设备型号
- 协议类型（ONVIF/RTSP等）
- 端口

### 5. 添加摄像机

- **单击**：选中摄像机，自动填充表单
- **双击**：编辑摄像机信息
- **点击"添加"按钮**：将摄像机添加到信号源列表

## ⚠️ 注意事项

### 网络要求

1. **路由可达**：确保本机可以访问目标网段
   - 检查防火墙设置
   - 确认路由器允许跨网段通信

2. **摄像机服务**：目标摄像机需要启用以下服务之一
   - ONVIF服务（推荐）
   - RTSP服务
   - HTTP API

### 性能提示

- 每个网段最多扫描254个主机（/24）
- 扫描时间取决于网段数量和超时设置
- 建议每次扫描不超过5个网段

### 常见问题

**Q: 扫描不到设备？**
A: 检查以下几点：

1. 网段配置是否正确（CIDR格式）
2. 网络是否可达（ping测试）
3. 防火墙是否阻止了UDP多播或TCP连接
4. 摄像机是否启用了ONVIF/RTSP服务

**Q: 扫描很慢？**
A: 可能原因：

1. 网段太大（如/16包含65536个IP）
2. 网络延迟高
3. 超时时间设置过长
建议：使用/24网段，减少同时扫描的网段数量

**Q: 如何知道摄像机的网段？**
A:

1. 查看摄像机说明书或标签
2. 登录路由器管理界面查看DHCP分配记录
3. 使用网络扫描工具（如Advanced IP Scanner）
4. 咨询网络管理员

## 🔧 技术实现

### 前端

- 组件：`AddSourceDialog.vue`
- 扫描模式：`scanMode`（'auto' | 'cross_subnet'）
- 网段列表：`crossSubnetList`（textarea输入）
- Tauri命令调用：`scan_specific_subnets`

### 后端

- Rust模块：`camera_discovery.rs`
- 核心方法：
  - `scan_specific_subnets()`：扫描指定网段列表
  - `scan_configured_subnets()`：扫描配置的网段
  - `generate_subnet_hosts_from_cidr()`：生成网段主机列表
- 并发扫描：使用`tokio::join_all`同时扫描多个主机

### 验证机制

1. ONVIF Probe请求
2. RTSP DESCRIBE请求
3. 厂商API检测（海康、大华等）
4. 非摄像机设备过滤
