# 网络摄像机行内编辑功能 - 快速开始

## 🎯 功能概述

本次更新为网络摄像机发现面板添加了**行内编辑**功能,允许用户直接在设备列表中修改配置参数,无需打开对话框。

### ✨ 新特性

- ✅ **原地编辑**: 点击"✏️ 编辑"即可在表格中直接修改
- ✅ **实时验证**: IP地址和端口号自动验证格式
- ✅ **智能保存**: 已注册设备自动更新后端配置
- ✅ **一键取消**: 支持恢复到编辑前的状态
- ✅ **批量操作**: 可同时编辑多个设备,互不干扰

## 📖 使用教程

### 步骤1: 扫描设备

1. 打开应用,进入"摄像机发现"页面
2. 选择扫描模式: **"🌐 多网卡扫描(推荐)"**
3. 点击 **"开始扫描"** 按钮
4. 等待扫描完成,查看设备列表

### 步骤2: 编辑设备配置

#### 2.1 进入编辑模式
```
找到目标设备 → 点击"✏️ 编辑"按钮
```

#### 2.2 修改参数

编辑状态下可以修改:
- **IP地址**: 直接输入新IP (如: `192.168.1.200`)
- **端口号**: 使用上下箭头或输入数字 (1-65535)
- **设备名称**: 输入自定义名称 (如: `会议室摄像机`)
- **用户名**: 输入登录用户名 (默认: `admin`)
- **密码**: 输入登录密码 (不显示现有值)

#### 2.3 保存或取消

- **💾 保存**: 验证并保存修改
  - 如果设备已注册: 立即更新后端配置
  - 如果设备未注册: 保存到本地列表
- **❌ 取消**: 放弃修改,恢复原始数据

### 步骤3: 验证修改

1. 保存后,设备列表会显示新的配置
2. 可以点击"配置"按钮查看详情
3. 或者尝试注册/连接设备验证配置正确性

## ⚙️ 配置说明

### IP地址格式验证

**有效格式**:
```
✅ 192.168.1.100
✅ 10.0.0.1
✅ 172.16.0.254
✅ 255.255.255.255
```

**无效格式**:
```
❌ 999.999.999.999  (超出范围)
❌ 192.168.1        (不完整)
❌ abc.def.ghi.jkl  (非数字)
❌ 192.168.1.1.1    (过多段)
```

### 端口号范围

```
有效范围: 1 - 65535

常用端口:
- 80: HTTP
- 554: RTSP
- 8000: 海康威视
- 8080: 通用HTTP代理
- 8899: 大华
```

## 🔍 常见问题

### Q1: 为什么保存时提示"设备未找到"?

**A**: 这表示设备尚未注册到系统。有两种处理方式:

1. **先注册再编辑**:
   ```
   点击"注册"按钮 → 填写信息 → 确认注册 → 然后再编辑
   ```

2. **直接编辑未注册设备**:
   ```
   编辑后保存,配置会保存到本地列表
   之后点击"注册"时会使用新配置
   ```

### Q2: 修改IP后设备ID会变吗?

**A**: 是的。设备ID通常基于IP地址生成,修改IP后ID会改变。

**影响**:
- 已注册的预置位可能需要重新设置
- 其他引用该设备ID的地方需要更新

**建议**: 仅在必要时修改IP地址

### Q3: 可以同时编辑多个设备吗?

**A**: 可以!每个设备的编辑状态是独立的。

```
设备A: 编辑中... ✅
设备B: 编辑中... ✅
设备C: 正常显示

→ 可以分别保存或取消,互不影响
```

### Q4: 密码字段为什么不显示现有值?

**A**: 出于安全考虑,密码不会明文显示。

**处理方式**:
- 如需修改密码,直接输入新密码
- 如不需修改,留空即可(保持原密码)

### Q5: 编辑后的配置会丢失吗?

**A**: 取决于设备状态:

- **已注册设备**: 配置保存在后端数据库,不会丢失
- **未注册设备**: 配置保存在浏览器localStorage,清除缓存会丢失

**建议**: 重要配置及时注册到系统

## 🛠️ 技术实现

### 前端 (Vue 3)

**核心逻辑**:
```javascript
// 开始编辑
const startEdit = (row) => {
  row._originalData = { ...row }  // 备份原始数据
  row.editing = true               // 进入编辑模式
}

// 保存编辑
const saveEdit = async (row) => {
  if (!isValidIp(row.address)) {
    ElMessage.error('IP地址格式不正确')
    return
  }
  
  await invoke('update_camera_config', {
    deviceId: row.deviceId,
    ip: row.address,
    port: row.port,
    // ...其他字段
  })
  
  row.editing = false
  delete row._originalData
}

// 取消编辑
const cancelEdit = (row) => {
  Object.assign(row, row._originalData)  // 恢复原始数据
  row.editing = false
  delete row._originalData
}
```

### 后端 (Rust + Tauri)

**命令处理**:
```rust
#[command]
pub async fn update_camera_config(
    device_id: String,
    name: Option<String>,
    username: Option<String>,
    password: Option<String>,
    ip: Option<String>,
    port: Option<u16>,
    manager: State<'_, PtzDeviceManager>,
) -> Result<String, String> {
    // 1. 获取现有设备
    let camera = manager.get(&device_id).await?;
    
    // 2. 注销旧设备
    manager.unregister(&device_id).await;
    
    // 3. 创建新设备实例
    let new_camera = OnvifCamera::new(...);
    
    // 4. 注册新设备
    manager.register(new_camera).await;
    
    Ok("配置已更新".into())
}
```
